# Personal portfolio — Evgeny Nemzer

Static portfolio site for [GitHub Pages](https://pages.github.com/).

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

Then visit `http://localhost:3000`.

## Deploy to GitHub Pages

1. Push this repo to GitHub (`njenia/personal-website`).
2. On GitHub: **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch **main** (or `master`) and folder **/ (root)**.
5. Save. After a minute or two the site is live at:

   **https://njenia.github.io/personal-website/**

### Shorter URL (optional)

For `https://njenia.github.io/` (no `/personal-website` path), create a repo named **`njenia.github.io`**, put these files in its root, and enable Pages the same way.

## Customize

Edit `index.html` for copy and links; `styles.css` for colors and layout.
